# میوه‌چین ۱٫۶٫۰ — آرت «پرمیوم» به سبک تصویر مرجع

این گزارش فقط چیزهایی را می‌گوید که واقعاً نوشته و اجرا شده است. هر ادعای
«تست شد» یا «بیلد شد» به یک اجرای واقعی در GitHub Actions وصل است.

## ۱) درخواست

کاربر تصویر یک پنل «آفرین!» را فرستاد و گفت:

> «طرح گرافیکی صفحات مثل این میخوام باشه»

یعنی کل بازی باید همان کیفیت لعاب‌دار، قاب‌بندی‌شده و سه‌بعدی بازی‌های کژوال
را داشته باشد؛ نه پنل‌های تخت وکتوری.

## ۲) مشخصات تصویر مرجع و معادل پیاده‌شده

| در تصویر مرجع | در کد |
|---|---|
| قاب طلایی سه‌لایه با بیول و لعاب | `Art.frame` — سه باند طلایی + بدنهٔ کرم چهاررنگ + `bevel` + `gloss` + خط مویی |
| پلاک چوبی سه‌بعدی با تاج و گل/برگ در گوشه‌ها | `Art.woodBody` (+ هالهٔ طلایی، رگه، بیول، برق، میخ) و `Art.woodTitle` (متن سه‌پاس) |
| چیپ سطح: چوب تیره + خط طلایی | چیپ نتیجه با گرادیان چوب + بیول + رینگ طلایی |
| سه سوکت ستاره با برگ در گوشه‌های پایین | `Art.socketPlate` / `Art.starSocket` با جفت برگ رنگی |
| پلیت زمردی امتیاز | گرادیان چهاررنگ زمرد + بیول + لعاب + رینگ طلایی |
| کپسول کرم با سکهٔ ستاره‌دار | `Art.rewardCapsule` — پهن‌تر شد و سکه به لبهٔ راست (RTL) رفت |
| دکمهٔ لیمویی براق + آبی سلطنتی | `Art.buttonSkin` بازنویسی شد: بدنهٔ چهاررنگ، بیول، نوار براق تا ۴۶٪، رینگ سفید، بالشتک تیره |
| باغ محو با بوکه و گل‌های ریز | `Art.buildGarden` — ۱۶ گوی بوکه، خورشید، تپه، پرچین، ویگنت |
| شخصیت دختر که از لبهٔ کارت بیرون می‌زند | لاله (`Character.kt`) در صفحهٔ نتیجه با حالت جشن/دلگیر |

## ۳) کامپوننت‌های جدید یا بازنویسی‌شده در `Art.kt`

| نام | کار |
|---|---|
| `gradRR` | گرادیان عمودی چندتوقفه درون مستطیل گرد |
| `dropShadow` | سایهٔ نرم بدون `BlurMaskFilter` (سه مستطیل پشت‌سرهم) |
| `gloss` | نوار براق بالای شکل با محو شدن تدریجی |
| `bevel` | لبهٔ داخلی: یک استروک با گرادیان عمودی، بریده‌شده داخل شکل (تیره بالا، روشن پایین) |
| `text3d` | سه‌پاس: خط دور، بدنهٔ گرادیانی، هایلایت بالای حروف؛ با پارامتر `alpha` |
| `leafRich`, `sprout`, `strawberry`, `lemon`, `berries` | تزئینات گیاهی/میوه‌ای براق |
| `woodBody`, `socketPlate` | جدا شدن بدنهٔ پلاک و صفحهٔ سوکت از متن/ستاره برای استفادهٔ دوباره |
| `frame`, `woodTitle`, `starSocket`, `rewardCapsule`, `buttonSkin`, `hudCard`, `goalChip`, `coinChip` | همه با لایه‌بندی جدید بازنویسی شدند |

## ۴) صفحه‌هایی که این تغییر را گرفتند

- **نتیجه (برد و باخت)**: قاب سه‌لایه، خوشهٔ برگ/گل/میوه در چهار گوشه، پلاک چوبی
  با تاج و گل، چیپ چوبی، سه سوکت ستاره با برگ، پلیت زمردی، کپسول RTL، دکمه‌های
  براق و لاله کنار پرچین.
- **خانه**: لوگو به تابلوی چوبی با تاج و خوشهٔ برگ زیرین تبدیل شد؛ چیپ سکه و جان
  گرادیان + بیول + لعاب گرفتند؛ کاشی‌های داک صفحهٔ نشستهٔ براق با رینگ طلایی.
- **نقشه**: نشان سطح جاری گرادیان زمردی سه‌رنگ + بیول + لعاب.
- **داخل بازی**: کارت امتیاز، کارت‌های HUD، چیپ‌های هدف و کاشی‌های بوستر همه
  بیول/لعاب گرفتند (هندسهٔ تخته و انیمیشن مهره‌ها دست‌نخورده).
- **فروشگاه/جایزه‌ها/تنظیمات/مکث** همین‌ها را از طریق `Art.frame` و `Art.woodTitle`
  به ارث می‌برند؛ هیچ صفحه‌ای استثنا نشد.

  جدیدی اضافه نشد — و این را صریح می‌گوییم: **آرت با تست واحد سنجیده نمی‌شود.**
- CI اجرای `40223601746` روی کامیت `b529913` (Unit tests + Compile + Sign +

## ۷) چیزهایی که هنوز کامل نیست (صادقانه)

1. **اسکرین‌شات دستگاه نداریم.** محیط ساخت JDK/SDK/شبیه‌ساز ندارد (دانلود JDK از
   GitHub Releases هم در این محفظه بسته است). تنها بازخورد بصری، ماکِ
   `design-preview/premium_result.png` است که با Pillow و از همان اعداد و
   دستور رنگ‌آمیزی کد ساخته شده — نه اسکرین‌شات Canvas.
2. **هنوز همهٔ صفحه‌ها تزئین اختصاصی نگرفته‌اند.** قاب/پلاک/دکمه/سوکت در همه‌جا
   پرمیوم شده، اما خوشهٔ گل و برگ فقط روی صفحهٔ نتیجه و لوگوی خانه است.
3. **هزینهٔ رندر**: هر `gloss`/`bevel` یک `clipPath` می‌زند (~۲۰ عدد در صفحهٔ
   نتیجه). روی گوشی‌های ضعیف اگر افت فریم دیدید، اولین گزینه کم‌کردن
   `Art.woodBody` روی صفحهٔ نتیجه است.
4. **پیش‌نمایش‌ها شبیه‌سازی‌اند.** `mock_ui.py` و `mock_result_160.py` هندسه و
   سایه را بازتولید می‌کنند، ولی رندر نهایی روی دستگاه ممکن است کمی متفاوت باشد.

## ۸) قدم بعدی پیشنهادی

- گرفتن یک اسکرین‌شات واقعی از دستگاه/شبیه‌ساز و تنظیم دقیق آلفاهای لعاب و بیول.
- بردن خوشه‌های گل/برگ به کارت‌های فروشگاه و جایزه‌ها.
- ساختن آرت اختصاصی برای پنل «شکست» (پس‌زمینهٔ بارانی/غروب) تا از پنل برد
  کاملاً قابل تشخیص باشد، بدون تغییر اقتصاد.
