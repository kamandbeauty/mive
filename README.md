# میوه‌چین

یک جورچین Match-3 آفلاین برای Android، با نمایش عمودی مخصوص بازی با یک دست؛ میوه‌های یک‌شکل را کنار هم جور کن، زنجیره بساز و هدف‌های ۱۰۰ مرحلهٔ باغ را کامل کن.

## روش بازی

- دو خانهٔ مجاور را لمس کن یا یکی را به سمت میوهٔ کناری بکش.
- جابه‌جایی فقط وقتی انجام می‌شود که دست‌کم سه میوهٔ هم‌شکل را جور کند.
- میوه‌های جور‌شده حذف می‌شوند، میوه‌های بالاتر پایین می‌آیند و میوه‌های تازه جای خالی را پر می‌کنند.
- هر مرحله هدف میوه‌ها، حداقل امتیاز و سقف حرکت مخصوص خودش را دارد.
- راهنمایی یک حرکت ممکن را نشان می‌دهد؛ اگر حرکتی نمانده باشد، صفحه دوباره چیده می‌شود.
- چکش، چیدمان دوباره و حرکت اضافهٔ خریداری‌شده از فروشگاه در نوار پایین صفحهٔ بازی مصرف می‌شوند؛ چکش با یک ضربه یک خانه را می‌شکند و یک لایه مانع را برمی‌دارد، چیدمان تخته را بدون هزینهٔ حرکت عوض می‌کند و حرکت اضافه پنج حرکت به همان مرحله می‌دهد. هر استفاده پیش از اعمال، اتمی از کیف کم می‌شود.
- پیشرفت، بهترین امتیاز و ستاره‌های مراحل روی دستگاه ذخیره می‌شوند؛ ۱۰۰ مرحله در نقشهٔ باغ تعریف شده است.

## اجرا و ساخت APK

```bash
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release --split-per-abi
flutter drive --driver=test_driver/integration_test.dart --target=integration_test/app_test.dart
```

APKهای آزمایشی برای ARM64، ARM 32-bit و x86_64 جداگانه ساخته می‌شوند. ساخت CI با کلید debug امضا می‌شود و برای انتشار در فروشگاه مناسب نیست.

## اقتصاد و تبلیغ جایزه‌دار

کیف سکه، تقویت‌کننده‌ها، جایزهٔ روزانه و صندوق‌های نقطه‌ای روی دستگاه ذخیره می‌شوند. تقویت‌کننده‌های خریداری‌شده در نوار پایین تخته مصرف می‌شوند؛ حرکت اضافه در پنجرهٔ باخت هم قابل استفاده است و مرحله را برمی‌گرداند. آگهی‌های جایزه‌دار از SDK رسمی Adivery استفاده می‌کنند و فقط پس از رضایت بازیکن بارگیری می‌شوند؛ بسته‌شدن عادی تبلیغ پاداش نمی‌دهد. پاداش روزانه آفلاین است و با تغییر ساعت دستگاه قابل دست‌کاری است.

برای ساخت انتشار، شناسه‌های واقعی Adivery را از متغیرهای محیطی `ADIVERY_APP_ID` و شناسه‌های جایگاه تبلیغ بگیر و از `scripts/build_android_release.sh` استفاده کن. اگر شناسه‌ها تنظیم نباشند، تبلیغات غیرفعال می‌ماند و بازی آفلاین کار می‌کند. جزئیات نسخهٔ SDK، رضایت و محدودیت‌های حریم خصوصی در [`docs/rewarded_ads.md`](docs/rewarded_ads.md) آمده است. SDK Flutter رسمی فعلاً در نسخهٔ سازگار با Dart 3 پیش‌انتشار است؛ پیش از انتشار فروشگاهی، نسخهٔ پایدار و سیاست حریم خصوصی را دوباره بررسی کن.
